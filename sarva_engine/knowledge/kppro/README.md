# KP Pro booklet in the SARVA engine

Installed. KP-PRO-METHODOLOGY.docx, the owner's 33 section booklet on KP Pro v15, with its text from pandoc, a section index with line
numbers, and KP_PRO_PROCEDURE.md, the English map. The KP rule files stay in the sibling repo KP-Pro-sutton, knowledge/kp_pro. The
guard treats the booklet as present when KP-PRO-METHODOLOGY.txt exists, and then requires the KP Pro EVIDENCE line to carry a
confidence word and a basis word.
