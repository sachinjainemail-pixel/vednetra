# Quad Dasha in the SARVA engine

Installed. QUAD-METHODOLOGY-INTRO.pdf and text (section 1 and the reading guide only), QUAD-REPORT-CONTRACT.md, QUAD_PROCEDURE.md.

Required before the Quad Dasha column can be run on rules. The full methodology file, sections 3 to 19. Save it here as
QUAD-FULL-METHODOLOGY.pdf, .txt or .md. The guard treats the Quad rules as present only when that file exists, and until then the
Quad cell reads NOT RUN QUAD RULES MISSING. The chart and dasha computation itself, which is validated, is available now through
the vednetra-quad runner.

Update of 17 November 2026.
